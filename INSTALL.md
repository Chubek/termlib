# Installing Termlib

## Requirements

A C11 compiler, CMake 3.15 or newer, POSIX threads, and Perl are required. The standard library also requires its vendored or configured third-party sources.

## Configure and install

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
cmake --install build --prefix "$HOME/.local"
```

The install includes `libtermlib`, Termscript libraries, the `termscript` executable, public C and C++ headers, the grammar, standard-library headers, companion modules, and the manual support files.

## Static linking

Use the static archives emitted by the build and link pthreads. Programs generated by `termscript -c` must link the runtime libraries and the native standard-library archive when they use `std.*` modules.
